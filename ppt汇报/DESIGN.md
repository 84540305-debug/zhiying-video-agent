# DESIGN.md · 知影 ZhiYing 汇报 PPT 设计稿

## 1. 画布与母版
- 画布尺寸：1280×720
- 母版三区：
  - A · 标题块：0–120px，主标题 32–40px bold
  - B · 内容区：120–660px，540px 可用
  - C · 页脚条：660–720px，左"知影 ZhiYing" + 右页码 `NN / 20`
- 页面 padding：上下 20px、左右 60px

## 2. 颜色系统（军绿主题，4 色）
| 角色 | Hex | 用途 |
|---|---|---|
| 主色 | `#2E7D4F` | 标题、强调、标题栏底色、主色块 |
| 辅色 | `#5AA87A` | 渐变终点、卡片头部、分隔线、图标 |
| 强调色 | `#FFD97A` | 金星 Logo、巨型数字、核心数据标注 |
| 背景 | `#F3F7F3` | 页面背景（浅军绿白） |
| 文本主色 | `#1C3226` | 正文（深墨绿） |
| 文本辅色 | `#54705E` | 次要文字、注释 |

### 色彩面积分配
| 色彩角色 | 面积占比 | 说明 |
|---|---|---|
| 主色 `#2E7D4F` | ≤ 55% | 标题、标题栏、强调色块 |
| 辅色 `#5AA87A` | ≤ 25% | 卡片背景、图表、分隔线 |
| 强调色 `#FFD97A` | ≤ 8% | 金星、巨型数字、核心标注 |
| 中性色 | 剩余 | 文本、页脚、边框 |

### 渐变方案
- 主渐变：`linear-gradient(135deg, #2E7D4F 0%, #5AA87A 100%)` → 封面/章节扉页/结束页背景
- 辅助渐变：`linear-gradient(135deg, #FFD97A 0%, #F0C050 100%)` → 金星 Logo 填充
- 半透明：`rgba(46,125,79,0.08)` → 卡片浅色覆盖

## 3. 字体系统
| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| H1 | 40px | bold | 封面/结束页主标题 |
| H2 | 32px | bold | 内容页标题 |
| H3 | 24px | bold | 章节扉页标题 |
| Body | 16px | normal | 正文 |
| Caption | 14px | normal | 页脚、注释、表格小字 |
| Code | 13px | normal | 代码块（Consolas 等宽） |
| MegaNum | 72px+ | bold | 巨型数字锚点 |

字体家族：`微软雅黑`（中文）+ `Segoe UI`（英文）+ `Consolas`（代码）

## 4. 装饰白名单
- 金色五角星 Logo（封面/结束页/页脚左侧）
- 军绿渐变背景条（标题栏底部 4px）
- 表格表头军绿底色
- 代码块军绿浅色背景 `#F0F7F3`

## 5. 页面类型映射
| 页面类型 | 标题位置 | 背景方案 | 特殊 |
|---|---|---|---|
| cover (01,20) | 居中 | 全屏军绿渐变+金星 | 可省略 C 区 |
| catalog (02) | A 区 | 白色 | 左标题+右列表 |
| section (03,06,09,15,19) | 居中 | 全屏军绿渐变 | 可省略 C 区 |
| content (04,05,07,08,10-14,16-18) | A 区 | 白色 | 标准三区 |
